# P0-a 안전 동작

- Launch와 제어 노드는 `mode:=fake`만 지원합니다. Fake 이동 허가는 시뮬레이션 파라미터 `/robot_node fake_motion_clear`로 표현합니다.
- Robot Node는 모든 Action에서 공통 실행 슬롯을 사용합니다. 실행 중 추가 Goal은 거절하며, 동작 전과 수행 중 이동 허가와 취소를 확인합니다.
- 관제는 최근 RobotStatus로 이동 허가를 확인합니다. 작업자 완료 후 3초 대기가 끝난 뒤에도 별도로 확인합니다.
- `stop`은 관제를 즉시 STOPPED로 전환하고 Robot Node에 정지를 요청합니다. 정지 응답은 수신한 계층의 래치 상태를 의미합니다. `resume`은 관제 작업 종료, Robot Node 정지 확인, 유휴 상태 및 이동 허가 확인을 거쳐 READY로 전환합니다.
- Action 접수·종료 여부가 불명확하면 상태를 STOPPED로 유지합니다. 취소나 정지된 작업을 재개하지 않으며 새 작업은 `check`로 시작합니다.
- 실물 도입 전 물리적 정지 회로, 작업자 접근 감지, 툴과 좌표 교정, 정지 우선순위, 통신 중단 대응, 제어 힘·토크 한계를 별도로 검증합니다.
